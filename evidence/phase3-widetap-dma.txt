== dma 11 (raw ADC) detail ==
Layout: per path 4 bytes = (I1,Q1,I0,Q0) little-endian int8: time order is bytes[2,3] then bytes[0,1]; path A = bytes 0-3,
path B = bytes 4-7. Evidence: corr(A0[n],A1[n]) 0.74 and corr(A0[n],A1[n+1]) 0.74 but corr(A0[n+1],A1[n]) 0.31,
